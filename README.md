# Google Calendar Mods

Tampermonkey юзерскрипты и модификации для Google Календаря.

## Скрипты:

### 1. Google Calendar Horizontal Day Timeline (`gcal_horizontal_day.user.js`)
Горизонтальный 24-часовой суточный таймлайн (как в видеоредакторах / ChronoTrack):
- Дорожки по календарям (Swimlanes): `Владислав`, `WORK`, `ВАЖНО`, `Завдання` и др.
- Полная адаптация под нативный Google Material 3 DOM (кнопка переключения вида, выпадающее меню видов).
- Два режима масштаба: «↔️ По ширині» (Fit) и «🔍 Скролл» (Zoom с ползунком).
- Красная вертикальная линия текущего времени («Зараз») с автообновлением.
- Кнопка «🎯 Зараз» для быстрого перехода к текущему времени.
- Обработка пересекающихся событий (автоматическое распределение по уровням высоты дорожки).
- Интеграция с нативным интерфейсом: клик по плашке открывает стандартную карточку события Google Calendar.
- Хоткей: **`H`** (или через выпадающее меню видов «Горизонтальний день»).
- Выход в стандартный вид: клик по любому виду («День», «Тиждень» и т.д.) или клавиши `D`, `W`, `M`, `Y`, `A`, `X`.

#### Установка в Tampermonkey по прямой ссылке:
Вставьте ссылку в поле **«Импорт из URL»** в настройках Tampermonkey:
```
https://raw.githubusercontent.com/OctopusBetter/Google-Calendar-Mods/main/gcal_horizontal_day.user.js
```

### 2. Google Calendar Scanner (`gcal_scanner.user.js`)
Инструмент для сканирования и анализа DOM Google Календаря:
- Сбор структуры интерактивных элементов, ролей, data-атрибутов и глобальных ключей.
- Экспорт снимков `calendar_dom.html` и `calendar_map.json`.
